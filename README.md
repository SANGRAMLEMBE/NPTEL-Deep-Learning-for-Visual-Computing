## 📌 Repository Overview
This repository contains my personal notes, assignment solutions, and code implementations for the **NPTEL** course **"Deep Learning for Visual Computing"**, offered by **IIT Kharagpur** and taught by **Prof. Debdoot Sheet**.

The course explores the theoretical foundations and practical applications of Deep Learning in computer vision, covering topics ranging from basic Neural Networks to advanced architectures like GANs and RNNs.

---

## 👨‍🏫 Course Details
* **Course Title:** Deep Learning for Visual Computing
* **Platform:** NPTEL (National Programme on Technology Enhanced Learning)
* **Institution:** IIT Kharagpur
* **Instructor:** Prof. Debdoot Sheet (Dept. of Electrical Engineering)
* **Duration:** 12 Weeks
